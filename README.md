# Automated Reporting and Analytics System

A Python-based automation project developed during internship to streamline report generation, data visualization, and email delivery.

## Overview

This system processes operational data, generates structured Excel reports, creates visual charts, and automatically sends reports to stakeholders on a scheduled basis.

## Features

- Automated data processing
- Structured Excel report generation
- Visual chart creation
- Scheduled hourly execution
- Automatic email delivery
- Reduced manual reporting effort

## Tech Stack

- Python
- Pandas
- OpenPyXL
- Matplotlib
- Schedule / Task Scheduler
- SMTP (Email Automation)
